Анімації: поява блоків при прокрутці, підняття карток, обертання чохла при наведенні,
висувний кошик, модалки, пульсація бейджа кошика, плаваючі градієнти в hero.

**Важливо про кошик:** він живе в памʼяті сторінки, не в localStorage — так просили
обмеження прев'ю. Після деплою на Cloudflare можна за 10 рядків додати збереження
кошика між візитами, якщо захочеш.

**Фото немає.** Замість фото — CSS-макети чохлів, які перефарбовуються під обраний колір
і мають фактуру: рифлення для RIMOWA, тканинне плетіння для Techwoven, шкіра для Leo,
прозорий корпус для Clear. Виглядає як товар, а не як заглушка. Коли будуть реальні фото —
міняється один рядок у функції `phoneHTML`.

## 3. Як задеплоїти на Cloudflare Pages

Так само, як intromax-site (розділ 11.4 мастера — Pages, не Worker):

1. Новий репозиторій на GitHub, напр. `baza-case-site`, залити вміст цієї папки.
2. Cloudflare → Workers & Pages → **`/pages/new/provider/github`** (не кнопка «Create application»).
3. Підключити репо, build command порожній, output `/`.
4. Settings → Environment variables → `TG_TOKEN` (Secret) і `TG_CHAT_ID` (Secret) →
   **обовʼязково редеплой**, інакше форма поверне 500.
5. Перевірити наскрізно: покласти товар у кошик, оформити, побачити повідомлення в Telegram.

Адреса вийде виду `baza-case-site.pages.dev` — для чернетки цього досить, домен не потрібен.

## 5. Що варто вирішити

- Онлайн-оплата (LiqPay / Monobank) — окремий обсяг і окрема ціна, зараз її немає.
- Збереження кошика між візитами — 10 рядків, вмикається після деплою.
- Хто оновлює каталог далі: він сам чи ти в рамках підтримки (озвучено 400 грн/міс, перший місяць безкоштовно).
- Якщо позицій стане більше 40 — товари варто винести в окремий `products.json`, щоб правити каталог, не чіпаючи HTML.
