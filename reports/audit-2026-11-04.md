# Аудит сайта BAZA CASE — 04.11.2026

Проверено: `index.html`, `functions/api/lead.js`, `img/`, история git (9 коммитов), живой сайт (только GET), вёрстка в Chromium на 360/390/414 px.
Ключи и личные данные в отчёт не включены. Цены, тексты, структура, оффер, функция заказов — **не менялись**, только отчёт.

## 5 самых важных находок

1. **Внутренний README публично доступен на живом сайте.** `README-Валентину.md` отдаётся GitHub Pages (проверено: HTTP 200 и по `.md`, и по `.html`). В нём — стоимость поддержки, готовое письмо клиенту, заметки «ціни треба перевірити». Так же публично лежит `functions/api/lead.js`. Нужно убрать файл из публикуемой папки/репозитория (или сделать репо приватным и деплоить Cloudflare).
2. **Номер заказа у клиента не совпадает с номером в Telegram.** Сервер создаёт свой `BC-…`, клиент игнорирует ответ и рисует свой (`index.html:944`). Клиент назовёт номер, которого нет у Максима.
3. **Сервер доверяет цене и сумме из браузера** (`lead.js:62,71`), нет защиты от спама (только honeypot; нет лимита, Turnstile, проверки Origin). Любой может слать фейковые заказы в Telegram Максима и подставлять цены.
4. **Цены 199 грн против 949–1100 грн** у однотипных силиконовых (`index.html:623,627,631`) — на витрине и в плитке категории «від 199 грн» (`:677`). Автор README сам отметил как «перевірити першим». На сайте при этом висит плашка «Чернетка… ціни потребують перевірки» (`:317`) — на живом сайте для клиентов.
5. **SEO-основа отсутствовала**: `og:image`/`twitter:image` были относительными (соцсети такую картинку не показывали), не было canonical, `robots.txt`, `sitemap.xml`, JSON-LD. **Исправлено в этом PR.**
